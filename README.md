# Рамка для фотографий

Приложение для добавления рамки к одной фотографии или всем
изображениям в папке.
[Качать туть последний](https://github.com/NikitinAndrei/FrameAdder/releases)

## Возможности

- JPG, JPEG, PNG и BMP как источник и результат;
- выбор папки с фотографиями или одного изображения;
- предпросмотр первой фотографии из папки;
- цвет рамки из системной палитры или в формате `#RRGGBB`, если прям хочется скопировать цвет;
- размер рамки от +0 до +200 % (от наибольшей стороны при квадрате);
- необязательное фоновое изображение, шоб текстурки можно было делать на фон;

При включённом режиме «Оквадратить» берётся наибольшая сторона, прибавляется заданный
процент и доводится до квадрата.
Если режим выключить, ширина и высота увеличиваются на заданный процент по отдельности.

Фон и исходная фотография центрируются без масштабирования. Большой фон
обрезается по границам результата. Если картинка больше картинки фона, то её не будет видно, я её не растягиваю, 
она сзади там.

Превью со сжатым фото для ускорения.

## Использование

1. Нажмите «Выбрать папку…», чтобы обработать все изображения из папки.
   Вложенные папки не обходятся.
2. Для одного файла дважды щёлкните по области превью или нажмите `Ctrl+O`.
3. Укажите папку для готовых файлов. По умолчанию это соседняя папка вида
   `<имя>_with_frame`.
4. Настройте процент, режим результата, цвет и при необходимости фон.
5. Нажмите «Добавить рамку» или `Ctrl+Enter`.

Для папки в превью используется первое поддерживаемое изображение в
алфавитном порядке. Готовые файлы получают исходные имена и расширения.


## ~~Шаболдочки~~ Шаблончики!
1. Выбираем шаблон;
2. Выбираем картинки двойным кликом;
3. Пока повороты работают только на 180. Для этого 1 клик по фото;
4. Сохранённое имя = сумма имён в шаблоне.

## Сборка EXE

Приложения-экзешники уже в релизах. Просто скачиваем и запускаем,
но если оч хочется внести изменений в форке, то вот командочки для своей сборки:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Готовый файл появится в `dist\AddingFrameToPhotos.exe`. Скрипт также может
создать служебные `build\` и `AddingFrameToPhotos.spec`;

Workflow **Build Windows EXE** доступен на вкладке Actions и автоматически
запускается для тегов формата `v*`, например `v1.0.0`. Собранный EXE можно
забрать из артефактов workflow.
